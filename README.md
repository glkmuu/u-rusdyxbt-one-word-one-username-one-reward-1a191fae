# One Word, One Username, One Reward

A program that writes the username `kamuu-gl` to `/output/entry.txt` — one word, one username, one reward. Entry for the make.fun bounty [u-rusdyxbt-one-word-one-username-one-reward-1a191fae](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae?utm_source=github&utm_medium=readme&utm_campaign=u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program writes exactly the 8 bytes `kamuu-gl` (no newline) to `entry.txt`, validates the length and that it is not whitespace, reads it back, and prints its SHA-256.

## Run

```sh
python3 main.py [output-dir]
```

Defaults to `/output` when no output directory is given (or set `OUTPUT_DIR`).

Deterministic: the same 8 bytes are written on every run.
